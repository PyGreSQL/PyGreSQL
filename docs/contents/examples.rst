Examples
========

The :doc:`postgres/index` that is part of the PyGreSQL documentation
shows some examples of using PostgreSQL with PyGreSQL.

Oleg Broytmann has written a simple example
`RGB database demo <https://phdru.name/Software/Python/#rgb_example>`_.

If you have an example application that uses PyGreSQL, please let us know
on the :doc:`mailing list <../community/index>`.
