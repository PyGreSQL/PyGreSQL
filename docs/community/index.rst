PyGreSQL Development and Support
================================

PyGreSQL is an open-source project created by a group of volunteers.
The source code and the issue tracker are hosted on GitHub, and the
documentation is published on GitHub Pages and Read the Docs.
The current maintainers are D'Arcy J.M. Cain (who also provides the
mailing list and the pygresql.org domain) and Christoph Zwerschke (who tries
to keep the code up to date and fix reported issues).
We would be glad to welcome more contributors so that PyGreSQL can be
further developed, modernized and improved.
